# Definition of Done

Applies later during the build. Draft now so acceptance criteria stay honest.

A story is **Done** when:

- [ ] Installed / implemented per the feature decision docs
- [ ] Safe (electrical, propane, structural, CO/smoke as applicable)
- [ ] Weight impact logged in [weight & balance](../02-architecture/weight-and-balance.md) if material
- [ ] Product row updated to `installed` in feature `products.md` + master BOM
- [ ] Photos / notes captured for future maintenance
- [ ] Shakedown check passed (criteria listed on the story)

Revise this list before Sprint 1 of the build phase.
