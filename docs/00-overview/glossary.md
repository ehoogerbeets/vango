# Glossary

Shared terms so feature docs stay consistent.

| Term | Meaning |
|------|---------|
| ADR | Architecture Decision Record — a dated, reasoned choice |
| BOM | Bill of Materials — master parts list |
| Epic | Large feature area; maps to a Jira Epic later |
| Story | Deliverable slice of an epic; maps to a Jira Story |
| House battery | Leisure / house electrical bank (separate from starter) |
| Shore power | External AC hookup (campground pedestal, etc.) |
| Grey water | Waste water from sink/shower (not toilet) |
| Black water | Toilet waste |
| Fresh water | Potable tank / supply |
| Fill filtration | Filters/strainers on the path **into** the fresh tank (pressurized, trickle, or rain) |
| Pre-pump strainer | Coarse protection between fresh tank and demand pump |
| PEX-A | Cross-linked polyethylene (type A) tubing — flexible fresh-water distribution choice for this build |
| UV irradiator | Ultraviolet disinfection stage; inactivates bacteria/viruses (needs clear water + power). On this van it is the LED UVC chamber in the fill-side **GoBluTech AR3** |
| GoBluTech AR3 | Compact 5-inch 4-stage fill filter + LED UVC (Blu Technology PURBLU). Plumbed before the fresh tank so no raw water enters storage |
| Filter inline | Valve position for a fill: shore, draft, and rain go through the AR3 into the tank. Also the short winterize air blast through the UV chamber |
| Bypass | Winterize-only valve position. AR3 is isolated and the shore inlet feeds house distribution for the air blow-out. Not a way to fill the tank |
| Accumulator / pressure tank | Small pressurized vessel that stores water so the pump cycles less and pressure feels steadier |
| Electric ball valve | Motorized valve (here: grey/black dump) open/close from controls/app |
| Tank level sensor | Electrical monitor of fresh/grey/black fill level (app-readable) |
| Instant EW | Instant / tankless electric water heater — **240V** class in this project |
| Pressurized fill | City/camp hose fill under pressure (use a regulator) |
| Trickle fill | Non-pressurized or slow fill (gravity, jugs, slow sources) |
| Off-grid | Operating without shore power / city water |
| Stealth | Low-profile overnight parking appearance |
| Payload | Remaining weight capacity after van + build |
| Battery floor zone | e-Sprinter under-floor traction battery span: **B-pillar → rear axle** — no drill / no under-mount tanks / tie-down mounts only |
| OEM tie-downs | Factory cargo floor attach points (pre-drilled) used for cabinetry in the battery floor zone |
| Wet aft | Layout pattern: shower + galley toward rear doors for gravity drain to aft under-mount tanks |
| RuuviTag Pro | Battery BLE sensor (temp / humidity / pressure) for interior zones |
| Weather station | Exterior sensor suite (temp, pressure, wind, humidity) feeding OpenVan |
| Solar thermal quick-connect | Side-of-van coupling for a deployable water/glycol collector → warm/hot tank loop |
| Cool Top Trail | Webasto **48V** rooftop heat pump (cool 12.3k BTU / heat 11.6k BTU). Drops into a 14" × 14" cutout |
| MaxxFan Mini Plus | MaxxAir roof fan with a fixed 4.1" rain shroud (no rising lid). Fits under the solar canopy |
| Dual MPPT | Two solar charge controllers: main canopy series string, plus an isolated narrow N-type string beside the Webasto |
