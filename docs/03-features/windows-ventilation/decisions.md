## Log

### D-01: Arctic Tern Overland acrylic cabin windows

- **Date:** 2026-10-14
- **Status:** `proposed`
- **Context:** Cargo van needs aftermarket glazing; weight and insulation matter.
- **Decision:** Prefer **Arctic Tern Overland classic double-pane acrylic** windows for cabin openings.
- **Why:** Lighter than glass; insulated panes; established overland product line.
- **Alternatives considered:**
  - Option A — Tempered glass RV windows
  - Option B — Single-pane acrylic
- **Consequences:** Must validate cut locations, seals, and film/coating compatibility with acrylic.
- **Supersedes / superseded by:** —

### D-02: Tint / film stack preference

- **Date:** 2026-10-14
- **Status:** `proposed`
- **Context:** Want thermal comfort and eco-minded treatments without locking a single product yet.
- **Decision:** Prefer **Greenfilm USA G-Cling** static cling on cabin glazing; ceramic coating (in/out) as alternate (incl. windshield); research **PDLC** on cabin acrylic only.
- **Why:** Cling is removable/eco-leaning; ceramic works where cling/PDLC is a poor fit; PDLC is optional privacy.
- **Alternatives considered:**
  - Option A — Dark dyed film only
  - Option B — No treatment (rely on HVAC + coverings)
- **Consequences:** Need acrylic adhesion/warranty checks before buying film rolls.
- **Supersedes / superseded by:** —
