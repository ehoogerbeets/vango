## Priority guide

`P0` MVP / first trip ([requirements](../01-van/requirements.md)) · `P1` important · `P2` nice-to-have · `P3` someday

MVP also needs a **settee** and **table** (eating/working) — own under layout / galley / interior until a living-area feature is split out.

## Adding a feature

1. Copy `docs/templates/feature-README.md` into `docs/03-features/<slug>/README.md`
2. Optionally add `decisions.md`, `products.md`, `stories.md` from templates
3. Register the feature in the table above
