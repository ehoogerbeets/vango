## Notes

- AR3 mounts in an **aft wet-core service bay** with clear wrench radius for the 5-inch canisters. This layout has no rear garage.
- Manual **bypass** and **filter inline** ball valves. Bypass is winterize-only: shore inlet → house lines, AR3 isolated. Filter inline is shore / draft / rain → AR3 → tank. A check keeps the bypass from putting untreated water in the tank.
- Shore inlet is standard city-water thread. Winterize threads a brass blow-out plug into it and regulates air to **30–40 PSI**. The same portable compressor used for tires does this job; it needs an adjustable regulator.
- Pre-pump strainer is a **quick-connect** so it can come off and the pump can run 5–10 seconds dry.
- Fresh-tank dump plus low-point drains that can be left open all winter.
- Shore fill still needs a **pressure regulator** before the fill manifold. The compressor has its own regulator, set to 30–40 PSI for the blow-out.
- Rain joins that manifold after a debris / first-flush stage (still open).
