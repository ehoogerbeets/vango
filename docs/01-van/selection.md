# Vehicle Selection

> Status: `decided`  
> Decision date: 2026-10-13  
> Target purchase: ~1.5–2 years (retirement)

## Chosen vehicle

- **Make / model / year:** Mercedes e-Sprinter cargo (_year at purchase_)
- **Configuration:** Cargo, LWB **170"**, **high roof**, **201 HP**, **113 kWh**, DC fast charge (~115 kW class)
- **Purchase target price:** **~$42K–$47K** used / fleet-leftover (vs ~$70K–$80K new)
- **Tow:** Aftermarket later — not factory tow package
- **ADR:** [ADR-0002](../05-decisions/0002-mercedes-e-sprinter-platform.md)

## Why this one

- Best balance for us vs e-Transit and ProMaster EV on reliability, space, aesthetics, used price, range, and battery size (see ADR comparison table).
- Cargo shell → we place windows; usually cheaper/more common than passenger.
- Factory high roof + **6'7"** raw height → path to 6'2" standing with ≤~5" floor+ceiling+clearance budget.
- Aligns with all-electric house ([ADR-0003](../05-decisions/0003-all-electric-house-systems.md)).

## Why not the others

| Rejected | Reason |
|----------|--------|
| Ford e-Transit | Better payload, NA service, new price — but smaller battery/range; used e-Sprinter wins on price for us |
| Ram ProMaster EV | Volume/HP/DCFC wins — loses on accessories, reliability/esthetics preference |
| New dealer e-Sprinter @ $70–80K | Used fleet leftovers deliver far better $/van |
| ICE Sprinter | Conflicts with electric / eco direction |
| Pop-top / raised roof | Hard constraint — not allowed |
